# Conceitos-de-UI-e-UX

- UI (Interface do Usuário) e UX (Experiência do Usuário)

- UI (Interface do Usuário) e UX (Experiência do Usuário) são áreas complementares do design digital: UX foca na jornada geral, usabilidade e lógica do produto (pesquisa, mapas de navegação, testes), enquanto UI cuida dos aspectos visuais e interativos (cores, botões, tipografia) que o usuário vê e toca, tornando a experiência agradável e intuitiva. UX define o "como funciona" e o "porquê", enquanto UI dá "forma e cor" ao produto, sendo ambos essenciais para criar um produto digital de sucesso.<br>
- UX Design (User Experience)
Foco: Experiência geral do usuário, tornando o produto útil, acessível e agradável.
O que faz: Pesquisa com usuários, define a arquitetura da informação, cria fluxos e jornadas, prototipa e testa usabilidade.
Pergunta-chave: "O usuário consegue atingir seu objetivo de forma fácil e satisfatória?". 
- UI Design (User Interface)
Foco: A parte visual e interativa do produto (o "look and feel").
O que faz: Cria cores, tipografia, ícones, botões, layouts e animações, dando vida à estrutura definida pelo UX.
Pergunta-chave: "Como a interface se parece e como o usuário interage com ela?". 
Relação entre UX e UI
- UX é o esqueleto, a base lógica; UI é a pele, a estética e a interação visual.
Um não existe sem o outro em um bom produto: um site lindo (UI) mas difícil de usar (UX) é ruim, assim como um site funcional (UX) mas feio e confuso (UI) também é.
O designer UX/UI combina essas habilidades para criar produtos digitais eficientes, intuitivos e atraentes, desde a pesquisa inicial até os elementos visuais finais.
